[사용법]
이 파일은 입력만 빠르게 찾는 목록이다. 의미와 예상 결과는 demo.txt에 있다.
[셸]은 운영체제 터미널, [REPL]은 mini-git>, [Python]은 >>> 입력이다.
번호, 제목, 설명, 프롬프트 표시는 입력하지 않는다. 명령 줄만 입력한다.
이 파일 전체를 셸 스크립트로 실행하거나 main.py에 통째로 리다이렉트하지 않는다.
각 D 명령은 새 REPL에서 순서대로 한 번씩 실행한다. 다시 시작하려면 exit 후 재실행한다.

닫히지 않은 따옴표 예시는 mini-git>에서만 입력한다. 셸에서 입력하면 셸이 추가 입력을 기다린다.

================================================================
4. 프로그램의 전체 명령 문법
================================================================
INIT <user_name>
BRANCH <branch_name>
SWITCH <branch_name>
COMMIT <message>
LOG
LOG --sort-by=date
LOG --sort-by=author
PATH <commit1> <commit2>
ANCESTORS <commit_hash>
SEARCH <keyword>
SEARCH --author=<name>
EXIT
QUIT

<>는 설명용 자리표시자이며 실제 입력에 넣지 않는다.
공백 포함 인자는 큰따옴표로 감싼다. 명령만 대소문자를 구분하지 않는다.
SEARCH의 여러 단어는 AND 토큰 검색이며, 부분 문자열·구문 검색이 아니다.
옵션은 --author=, --sort-by=의 명시된 표기를 사용한다.
기본 LOG는 모든 커밋을 부모 우선으로, 정렬 LOG는 선택한 기준의 오름차순으로 출력한다.
